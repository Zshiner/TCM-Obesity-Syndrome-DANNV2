# 外部测试集预测概率

`外部测试集预测概率.csv`：12 个学习器 × 5 个种子 × 308 例 × 11 个证素，共 203280 行。论文外部测试集上的全部指标、区间与检验都由这些预测算出（真值另需病案数据）。表里不含任何特征，也不含真值。

| 列 | 含义 |
|---|---|
| `case_id` | 外部测试集内的病例序号 0–307，即数据文件 `test_samples` 里的位置（第 0 例起） |
| `learner` | 学习器：knn、decision_tree、random_forest、extra_trees、dannv2_beta、realmlp、tabpfn_v3、tabicl、tabdpt、deepseek、glm、qwen |
| `seed` | 随机种子 0–4 |
| `label` | 证素 |
| `y_prob` | 该证素的预测概率（数值与论文存档逐字相同，未重新取舍小数位） |
| `y_pred` | 论文主口径下的判定：9 个本地模型为“概率 ≥ 部署阈值”（阈值见 `results/部署阈值.csv`）；3 个大模型为模型自己的判定（回答里选中的证素记 1） |

读数时要逐位精确，请用 `pandas.read_csv(..., float_precision="round_trip")`。pandas 默认的快速解析偶尔会在末位差 1（约 1e-16）。按这种方式读出的概率与论文存档的预测文件 60 组（学习器 × 种子）全部逐位相同。

关于大模型：三家大模型零样本调用，每例只问一次，5 个种子共用同一个回答，所以各种子的行完全相同。它们的 `y_prob` 是模型对选中证素自报的置信度，没选中的证素记 0，不是校准过的概率。
