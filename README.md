# 基于分布感知算法的低算力场景肥胖症可解释性智能辨证研究：复现包

论文《基于分布感知算法的低算力场景肥胖症可解释性智能辨证研究》的公开复现包，包括实验定义、全部实验结果、外部测试集预测概率、可解释性结果、分布感知网络 DANNV2-beta 的源码，以及 5 个学习器各随机种子的最终模型（部分包含原始数据故未公开，详见下文“最终模型”）。

**本仓库不含任何病案级数据。** 病案数据可向通讯作者发邮件申请。

## 研究概况

- **数据**：1586 例肥胖症中医文献病案，按发表年份划分。2018 年以前发表或年份未载的 1278 例为训练集；2018 年及以后发表的 308 例为时间外部测试集，测试集不参与任何调参、阈值选择与模型选择。特征 348 项（年龄、性别、病程及 345 项症状、舌象、脉象）；证素标签 11 项（心、脾、肝、肾、痰、湿、热、气滞、血瘀、气虚、阳虚），为多标签任务。
- **模型**：分布感知网络 DANNV2-beta，与 11 种对照模型比较，共 12 个学习器。
  - 预训练表格基础模型：TabPFN v3、TabICL、TabDPT。
  - 深度学习模型：RealMLP。
  - 经典机器学习模型：随机森林、ExtraTrees、K 近邻、决策树。
  - 通用大语言模型（零样本）：DeepSeek-V4-Pro、GLM-5.3、Qwen3.8-Max。
- **验证方案**：外 5 折、内 3 折的嵌套交叉验证。需要调参的模型用 Optuna TPE 每个外层折各调 200 次，最终模型在全部训练集上另调一次。判定阈值逐证素选取：交叉验证用嵌套阈值，外部测试集用部署阈值。整个流程在 5 个随机种子（0–4）上独立重复。外部测试集上做患者级 bootstrap（10000 次）区间，模型间做成对 bootstrap 检验，每项指标内的两两比较按 Holm 法校正。
- **评价**：分类性能（主指标 Macro-F1，另有 13 项辅助指标）、概率校准（Brier 分数与校准曲线）、临床效用（决策曲线）、计算开销、可解释性。

### 主要结果（外部测试集，摘自 [表 2](results/表2_总体性能_外部测试集.md)）

| 学习器 | Macro-F1 | Brier 分数 |
|---|---|---|
| KNN | 0.700 ± 0.003 [0.672, 0.724] | 0.132 ± <0.001 [0.126, 0.139] |
| Decision Tree | 0.587 ± 0.005 [0.560, 0.611] | 0.155 ± 0.003 [0.146, 0.164] |
| Random Forest | 0.771 ± 0.004 [0.746, 0.791]† | 0.128 ± 0.002 [0.123, 0.134] |
| Extra Trees | 0.769 ± 0.008 [0.746, 0.790]† | 0.132 ± 0.003 [0.126, 0.138] |
| **DANNV2-beta** | **0.784 ± 0.006 [0.761, 0.803]** | **0.082 ± 0.001 [0.076, 0.089]** |
| RealMLP | 0.766 ± 0.012 [0.744, 0.785]† | 0.094 ± 0.003 [0.087, 0.100] |
| TabPFN v3 | 0.796 ± 0.006 [0.773, 0.815]† | 0.087 ± 0.001 [0.082, 0.092]† |
| TabICL | 0.802 ± 0.006 [0.779, 0.822]† | 0.079 ± <0.001 [0.073, 0.085]† |
| TabDPT | 0.739 ± 0.008 [0.714, 0.760] | 0.104 ± 0.001 [0.097, 0.111] |
| DeepSeek-V4-Pro | 0.706 ± 0 [0.685, 0.726] | 0.142 ± 0 [0.131, 0.152] |
| GLM-5.3 | 0.684 ± 0 [0.662, 0.704] | 0.125 ± 0 [0.117, 0.134] |
| Qwen3.8-Max | 0.678 ± 0 [0.657, 0.698] | 0.155 ± 0 [0.145, 0.166] |

表中读数方法（同论文）：

- “±”后是 5 个随机种子之间的标准差，只反映换种子带来的波动，不是置信区间。
- 方括号内是合并种子的患者级 bootstrap 95% 区间。
- † 表示经成对 bootstrap 检验（Holm 校正），与 DANNV2-beta 的差异无统计学意义。两个模型有无差异，看成对检验（[表 5](results/表5_成对检验_外部测试集.md) 与 [`成对检验_Holm.csv`](results/成对检验_Holm.csv)），不看区间是否重叠。
- 学习器按实验定义的顺序排列，不代表名次。
- 大模型每例只调用一次，各种子共用同一回答，所以“±”为 0。

## 最终模型

公开了 5 个学习器 × 5 个种子共 25 个最终模型，放在 [GitHub Release v1.0](https://github.com/Zshiner/TCM-Obesity-Syndrome-DANNV2/releases/tag/v1.0) 附件里。它们由实验时保存的原模型文件导出，只去掉了对实验框架的依赖；在训练用的服务器上，对外部测试集的预测与论文存档逐位一致。文件名、SHA-256 与核对结论见 [`models/模型清单.csv`](models/模型清单.csv)，导出与核对的经过和用法见 [`models/README.md`](models/README.md)。

| 学习器 | 最终模型 | 原因 |
|---|---|---|
| Decision Tree、Random Forest、Extra Trees、DANNV2-beta、RealMLP | 已公开 | — |
| KNN | 不公开 | K 近邻没有可学习的权重，模型文件里存的就是全部训练病案，公开它等于公开病案数据 |
| TabPFN v3 | 不公开 | 预训练基础模型靠上下文学习，拟合时把全部训练病案存进模型，预测时连同待测病例一起送入预训练网络，模型文件里同样存着全部训练病案 |
| TabICL、TabDPT | 没有模型文件 | 同为上下文学习，模型就是“预训练权重 + 全部训练病案”；实验定义设定不保存，保存了也会因含训练病案而不公开 |
| DeepSeek-V4-Pro、GLM-5.3、Qwen3.8-Max | 没有模型文件 | 经厂商接口零样本调用，没有训练或保存模型 |

没有公开模型的学习器，外部测试集预测概率照样完整公开在 `predictions/`。

## 不需要数据就能做的

- **查看与引用全部结果**：`results/`、`predictions/`。
- **由汇总重新排出论文表格**（只需 numpy、pandas，不需要数据和实验框架）：

  ```
  python scripts/build_paper_tables_v4.py --summary bishan_tizhong/results/summary --out <输出目录> \
      --label-term 证素 --explain bishan_tizhong/explain --reference dannv2_beta
  ```

  输出的 `主结果/` 与本仓库的 `results/` 逐文件内容相同（换行符随操作系统而异）。`大模型调用统计.csv` 要读大模型的原始回答缓存，缓存含病例文字，不随包，所以这一个文件不会生成。
- **用最终模型预测新病例**：见 [`models/README.md`](models/README.md)。
- **审计实验过程**：每个分片的逐折结果、每次调参试验的参数与得分、每个最终模型的构造参数与运行种子，都在 `bishan_tizhong/results/shards/`。

## 申请到数据后能做的

- 用公开的最终模型对外部测试集重新预测，与 `predictions/` 比对，并复算全部指标、区间与检验。在训练用的服务器上 25 个模型全部逐位一致；换到其他设备，树模型仍逐位一致，DANNV2-beta 与 RealMLP 有不超过 10⁻⁶ 的浮点差异，判定不变（见 [`models/模型清单.csv`](models/模型清单.csv)）。
- 用 `dannv2_beta/` 源码重训 DANNV2-beta。换一张显卡重训与论文会差多少，见下文“复现预期”。
- 完整重跑整个实验（嵌套交叉验证、调参、阈值选择、bootstrap 检验），需要课题组自研的中医智能诊断实验框架 TCMHUBD。框架源码暂未随本仓库公开，需要时请与通讯作者联系。分片里被剔除的预测文件，其 SHA-256 仍记在 `*.npz.meta.json` 与 `bishan_tizhong/results/export/file_index.csv` 里，重跑后可以逐文件比对。

## 复现预期

| 做法 | 与论文的一致程度 |
|---|---|
| 用 `predictions/` 的预测概率复算指标（真值需申请病案数据） | 一致 |
| 用公开的最终模型重新预测 | 在训练用的服务器上逐位一致；换设备后树模型仍逐位一致，DANNV2-beta、RealMLP 的概率差不超过 10⁻⁶，判定不变 |
| 在 CPU 上按记录重训 Decision Tree、Random Forest、Extra Trees | Windows 上实测：15 个模型中 14 个逐位一致，Random Forest 种子 1 的概率最大差 4 × 10⁻⁵，判定不变 |
| 换一张显卡按记录重训 DANNV2-beta、RealMLP | 不能逐位一致，指标有小幅出入，见下表 |

GPU 训练的结果与软硬件环境有关。在训练用的环境（NVIDIA A100 80GB，torch 2.6.0+cu124）里按记录重训，结果逐位一致；换了显卡或 torch 版本，训练中的浮点舍入差异会逐步累积，得到的是另一个模型。我们在另一张显卡（RTX 5090 D，torch 2.11.0，Windows）上，用实验框架按记录的参数与种子，把两个模型的 5 个种子各重训一次，再用论文的部署阈值在外部测试集上比较：

| 学习器 | 指标 | 论文（5 种子均值 ± 标准差） | 换显卡重训（5 种子均值） | 平均差 | 平均差 ÷ 种子标准差 |
|---|---|---|---|---|---|
| DANNV2-beta | Macro-F1 | 0.784 ± 0.006 | 0.783 | −0.001 | 0.13 |
| DANNV2-beta | Brier 分数 | 0.0825 ± 0.0009 | 0.0831 | +0.0006 | 0.65 |
| DANNV2-beta | Macro-AUROC | 0.9365 ± 0.0012 | 0.9363 | −0.0003 | 0.24 |
| RealMLP | Macro-F1 | 0.766 ± 0.012 | 0.763 | −0.004 | 0.31 |
| RealMLP | Brier 分数 | 0.0936 ± 0.0027 | 0.0957 | +0.0021 | 0.79 |
| RealMLP | Macro-AUROC | 0.919 ± 0.006 | 0.910 | −0.009 | 1.51 |

- **DANNV2-beta**：15 项指标的平均差都不超过种子间标准差的 0.65 倍。逐例判定约有 1%–2% 翻转（每个种子 3388 个判定中 34–64 个），正负相抵，指标几乎不变。
- **RealMLP**：对数值误差更敏感，约 8% 的判定翻转（每个种子 262–299 个）。单个种子的 Macro-F1 最多差 0.020；Macro-AUROC 平均低 0.009，为种子间标准差的 1.5 倍，是 15 项指标中偏差最大的一项。
- 两个模型 15 项指标的 5 种子均值，都落在论文的合并种子 95% 区间内。
- 自己换环境重训时，可以按这个幅度判断：与论文的差别在种子间波动和 95% 区间之内，属于正常；明显超出时，先核对数据的 SHA-256、依赖版本、随机种子与输入精度（RealMLP 的输入为 float32）。

全部 15 项指标见 [`models/换显卡重训_指标汇总.csv`](models/换显卡重训_指标汇总.csv)，逐种子的指标、概率差与判定翻转数见 [`models/换显卡重训_逐种子.csv`](models/换显卡重训_逐种子.csv)。计算脚本是 [`models/compare_rebuild_metrics.py`](models/compare_rebuild_metrics.py)，要读含特征与真值的存档预测，仅供查阅。脚本先用论文存档的预测复算：150 个指标值与论文逐种子长表的最大差为 10⁻¹⁶，口径一致。KNN 与三个预训练基础模型没有做重训对比。

## 通用大语言模型的调用方式

三家模型经各自的 OpenAI 兼容接口零样本调用，接口模型名为 `deepseek-v4-pro`、`glm-5.3`、`qwen3.8-max-0902`，均于 2026 年 10 月 13 日调用。调用设置：

- 思维模式开；温度、top_p、最大输出长度都用各家缺省值；不加系统提示。
- 三家用同一提示词，请求全文逐字节相同。每例只调用一次，各种子共用同一回答。
- 不使用训练数据，不调参，不选阈值：依赖阈值的指标取模型自己的判定。

提示词模板如下（`{病例文字}` 处换成该病例记载为阳性的表现，首行为年龄、性别、病程）：

```
你是一位经验丰富的中医专家。
患者病案记载的表现如下（未列出的表现病案中未记载）：
{病例文字}
请从以下候选证素中选出所有适用的（可多选）：心、脾、肝、肾、痰、湿、热、气滞、血瘀、气虚、阳虚
out 中只能使用候选列表里的原词，不要改写、合并或增减字词。
请以 JSON 格式回答，格式为：
{"out": ["证素1", "证素2"], "prob": [置信度1(0~1之间的小数), 置信度2(0~1之间的小数)]}
注意：prob 必须是 0~1 之间的小数（fraction），例如 0.85；不要使用百分制（如 85）。
只输出这一个 JSON 对象，不要输出分析过程或其他文字。
```

回答里选中的证素记阳性，`prob` 作为它们的概率，没选中的证素概率记 0。每次调用的耗时与 token 统计见 [`results/大模型调用统计.csv`](results/大模型调用统计.csv)。
