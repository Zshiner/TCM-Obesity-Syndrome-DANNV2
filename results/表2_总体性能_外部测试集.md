# 表 2　总体性能（外部测试集）

外部测试集：每个种子用全量训练的模型评估一次，表中是各种子的均值 ± 标准差，方括号内是合并种子的 bootstrap 95% 区间。
“±”后面是随机种子之间的标准差，只反映换种子带来的波动（分折方式、调参路径、训练随机性），不是置信区间，不能用来判断两个模型的差别是否显著。学习器按定义文件里的顺序排列，不代表优劣。
“[ , ]”是合并种子的 bootstrap 95% 区间：对外部测试集做患者级重抽样，每次重抽样对 5 个种子各算一遍指标后取均值，再取 2.5% 与 97.5% 百分位（重抽 10000 次、公共索引矩阵种子 0）。它是“跨种子均值”这个点估计的测试集抽样区间，条件于冻结的模型与阈值，不含训练与调参的随机性，未作多重比较校正。逐种子的区间在 `外部测试集_逐种子置信区间.csv`。
两个模型有无差异看成对检验（表 5 与 `成对检验_Holm.csv`），不看区间或“±”是否重叠。
† 表示经成对 bootstrap 检验（每项指标内全部两两比较按 Holm 法校正），与 DANNV2-beta 的差异无统计学意义；未标 † 的与 DANNV2-beta 差异有统计学意义；DANNV2-beta 本行不标。
