# 数据

**本仓库不含病案数据。** 病案数据可向论文通讯作者发邮件申请。

## 数据概况

- 来源：从博览医书、古今医案云平台、杏林园、中医智库与中国知网 5 个数据库检出 3220 例肥胖相关中医病案，按纳入与排除标准筛选后得 1586 例（标准见论文 1.2、1.3 节）。每例是一份文献病案的初诊记录，重复转载已去重，每行对应一名患者。
- 划分：按发表年份划分。2018 年以前发表或年份未载的 1278 例为训练集（开发集）；2018 年及以后发表的 308 例为时间外部测试集。测试集不参与任何调参、阈值选择与模型选择。
- 特征 348 项：年龄、性别、病程，加 345 项广义症状（症状、舌象、脉象）。证素标签 11 项：心、脾、肝、肾、痰、湿、热、气滞、血瘀、气虚、阳虚。
- 列名、角色与编码见 [`数据字典.csv`](数据字典.csv)。列顺序就是数据文件里的顺序，也是模型的输入顺序。

## 申请到数据之后

把数据文件放到 `bishan_tizhong/data/obesity_syndrome/data.json`，并先核对 SHA-256，确认与论文所用的是同一份（`data_json_sha256.txt`）：

```
736e0f11ac18419ba786d1277dd55980b4184f4e0e1f4a4c6d419f08f5093df1  obesity_syndrome/data.json
```

文件是一个 JSON 对象：`feature_names`（348 个）、`label_names`（11 个）、`train_samples`（1278 例）、`test_samples`（308 例），每例为 `{"features": [...348 个数...], "labels": [...11 个 0/1...]}`。`test_samples` 的顺序就是 `predictions/` 里 `case_id` 0–307 的顺序。

`.gitignore` 已排除这个目录，防止数据被误提交。
